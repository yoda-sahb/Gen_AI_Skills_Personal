# Worked case trace — fictional attribution problem

**Evidence class: worked hypothesis, not production invention.** These stages illustrate what the Samurai method would produce from a fictional brief using known marketing experimentation principles. They do not establish what any particular manufacturer has or has not built.

## Before the reframe

Requested: "Clean fragmented affiliate, commerce, device and service data into a golden first-party dataset and fix attribution."

Conventional response: canonical schema → ETL → entity resolution → wider attribution model. Useful for quality of existing records; does not guarantee observation of missing private referrals and offline purchases.

## Seven-stage trace

| Stage | Candidate thinking |
| --- | --- |
| Breadth | Data, media, retailer economics, device ownership, household behavior, service, privacy, experimentation |
| Abstraction | Attribution conflates (a) consistency of existing records, (b) identification of consumers across sources, (c) individual causal paths that were never observed, and (d) the future state needed to serve customers |
| Analogy | Control-system observability and causal experimentation distinguish impossible reconstruction from feasible new measurements; this analogy was supplied within the working case, **not independently retrieved by a trainee** |
| Synthesis | Mark data quality, identity, actual direct observations, and causal effects as separate evidence types; diagnose MIXED rather than a generic data problem |
| Architecture | Reuse customer profile and agent substrate; create consent-scoped goal/action/outcome records only when useful; in parallel, use legitimate randomized or geographic outcome tests |
| Invention | **Boundary-Aware Outcome Loop:** actionable customer context + independent lift learning + typed evidence provenance. A composed design proposal, **not proven globally novel** |
| Execution | Test a narrow high-utility product-help journey; measure real task success and permission; separately test aggregate marketing lift only if a reliable outcome and feasible experiment exist; graduate reusable state/learning conventions to operating owners |

## Invention candidate: Boundary-Aware Outcome Loop

**Customer value first:** an appliance owner gets better recipes, setup, maintenance, or troubleshooting when prior goals and actions can be remembered with permission.

**New-to-the-problem mechanism:** each useful interaction can yield a scoped **context-to-outcome receipt**:

`customer-approved goal → product/context → eligible action → action taken → feedback/outcome → freshness/provenance/permission`

No inferred private-social graph. No retroactive reconstruction of unknown pathways. Use existing profile, conversational-agent and service products if they already support the mechanism.

**Marketing learning stays separate:** randomized or geographically balanced experiments can estimate campaign-level incrementality without observing the full private journey, *if* a sufficiently reliable downstream outcome measure exists. If retail outcomes are absent, return `EVIDENCE_UNAVAILABLE` rather than inventing precision.

**Decision evidence type:** distinguish `DIRECT_OBSERVATION`, `CUSTOMER_REPORTED`, `INFERRED`, `EXPERIMENTAL_ESTIMATE`, `UNKNOWN`, and `NOT_PERMITTED`. This prevents algorithmic certainty laundering.

## Kill criteria

1. Real utility does not increase the targeted task success/retention while preserving customer trust.
2. Context receipt duplicates existing product/agent capabilities without useful added decision state.
3. Permission uptake is too low, or biased enough that the generalization/economics do not hold.
4. Product context cannot be linked to actions/outcomes within acceptable privacy and operational constraints.
5. No credible measurement design can link campaigns to an appropriate aggregate outcome, so marketing-lift claims are withheld.
6. Human-system ownership cannot support maintenance and cross-product reuse after a pilot.

## No overclaim

Neither first-party data, outcome logging, identity resolution, incrementality, nor the general concept of a decision contract is newly invented globally. The proposed differentiation is the **careful combination** in a company-specific value loop and disciplined preservation of what remains unobservable. Patent/IP novelty, deployment and commercial lift are untested.
